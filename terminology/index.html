ID terminology, in plain English.

Identification documents contain specialized terms, codes and security features. This directory explains what those terms mean without assuming you already know the jargon.

Why these terms matter

Understanding the language on an identification document makes it easier to read forms, compare document features and follow official instructions. A term can have a specific meaning in one system and a broader meaning in everyday language, so context matters.

Document number

An identifier assigned to a particular document by its issuing authority.

Issue date

The date a document was issued or became effective.

Expiration date

The date through which a document is valid, subject to the issuer’s rules.

Date of birth

A person’s birth date, commonly printed on identity documents.

MRZ

Machine-readable zone: standardized lines of characters used on certain travel documents.

Barcode

A machine-readable pattern that can encode information for scanning.

QR code

A two-dimensional machine-readable code that can store information or link to digital content.

Hologram

A visual security feature that can change appearance when viewed from different angles.

Security laminate

A protective layer incorporated into some documents to protect printed information and may include security elements.

Photo identification

Identification that includes a photograph intended to help establish that the document belongs to the person presenting it.

Biometrics

Measurements or characteristics used for automated recognition or verification of a person.

A printed feature does not, by itself, prove that a document is genuine or acceptable for a particular purpose. Verification methods and requirements depend on the issuer and the situation.
